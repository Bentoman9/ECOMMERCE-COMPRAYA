# ECOMMERCE-COMPRAYA

Sistema de comercio electrónico desarrollado con **CodeIgniter** y **PHP**, enfocado en la gestión de ventas y control de inventario en tiempo real.

## 🚀 Características principales
- **Gestión de Ventas:** Automatización del ciclo de ventas completo.
- **Control de Stock:** Sincronización de inventario en tiempo real.
- **Arquitectura:** Implementación de patrón MVC (Modelo-Vista-Controlador).
- **Base de Datos:** Integración con MySQL (administrada mediante phpMyAdmin).

## 🛠️ Tecnologías utilizadas
- **Backend:** PHP, CodeIgniter.
- **Base de Datos:** MySQL / MariaDB (phpMyAdmin).
- **Frontend:** HTML5, CSS3, JavaScript, Bootstrap.

## ⚙️ Configuración y Ejecución
1. Clonar el repositorio en tu entorno local (ej. htdocs de XAMPP).
2. Crear una base de datos en **phpMyAdmin** e importar el archivo `.sql` del proyecto.
3. Configurar la conexión a la base de datos en el archivo `application/config/database.php`.
